## Game Versions

### V1 Classic (`index-v1.html`)
The original 2D battle simulator with authentic D&D mechanics.
- 15 iconic D&D monsters
- D20 combat system with initiative, AC, saving throws
- Special abilities & legendary actions
- Parchment-style UI theme

### V2 Enhanced (`index-v2.html`)
Extended roster with team battles and tournament mode.
- 30+ monsters
- Team battles
- Tournament mode (bracket-style)
- Manual combat option

### V3 3D Ultimate (`index-v3-3d.html`)
Full 3D arena with immersive combat and epic soundscape.
- **50+ monsters** with complete D&D 5e stats
- **3D arena** powered by Three.js
- **Epic soundtrack** with procedural music & sound FX
- **Team battles** up to 4v4
- **Tournament mode** with 8-monster bracket
- **Manual combat** - control your monster's actions
- **Status effects** - stunned, poisoned, charmed, frightened, paralyzed
- **Statistics** - win/loss tracking & leaderboard

## How to Run Locally

```bash
# Clone the repo
git clone https://github.com/hum-ae-n/GameTest.git
cd GameTest

# Option 1: Open directly
open index.html

# Option 2: Use a local server
npx serve .
# Then visit http://localhost:3000
```
